# 04 — Facilitator Flow

This section specifies every screen, state, modal, and interaction that the facilitator (session owner) encounters during a Work Audit session. The facilitator creates the session, shares the link, controls the session lifecycle, classifies activities during discussion, and exports results.

## Journey Summary

Home page (create session) → Lobby (share link + wait for engineers) → Active phase (live view, matrix view, grouped view) → Close submissions → Discussion phase (classify each activity in discuss view) → Export results
