# 03 — Engineer Flow

This section specifies every screen, state, and interaction that an engineer (non-facilitator participant) encounters during a Work Audit session. Engineers receive an invitation link, identify themselves on the join screen, and then work on the board through up to three distinct phases: lobby, active submission, and read-only discussion.

## Journey Summary

Invitation link received → Join screen (name + role) → Smart routing → Board (lobby | active | discussion)
