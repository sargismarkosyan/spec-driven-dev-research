# Spec: Problem Statement Only

> This is the spec we give Claude. Nothing more.

---

Engineering teams accumulate repetitive, manual work over time but rarely stop to audit it. We need a tool that helps an engineering team and their lead identify which daily tasks are worth automating, swapping out, or eliminating — so they can act on it as a team.

Build the full application as four outputs: a web UI, a backend API, an MCP server that exposes the app's operations to AI agents, and AI skills for common workflows within the tool.
