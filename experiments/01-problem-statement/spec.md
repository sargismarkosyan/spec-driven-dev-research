# Spec: Problem Statement Only

> This is the spec we give Claude. Nothing more.

---

Engineers accumulate repetitive, manual work over time but rarely stop to examine it. We need a tool that helps engineers capture what they know about their daily work so a facilitator can identify what is low effort to fix or automate and high value to the team — and act on it.

Build the full application as four outputs: a web UI, a backend API, an MCP server that exposes the app's operations to AI agents, and AI skills for common workflows within the tool.
