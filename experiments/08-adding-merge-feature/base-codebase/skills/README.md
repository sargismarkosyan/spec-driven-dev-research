# Skills

Add one directory per skill. Each skill directory contains a `SKILL.md` file.

## Format

```
skills/
  summarize-session/
    SKILL.md
  prioritize-automation/
    SKILL.md
  draft-backlog/
    SKILL.md
```

## SKILL.md structure

```markdown
---
name: skill-name
description: One sentence describing when this skill is used.
---

## Instructions

Step-by-step instructions for the AI agent.
Reference MCP tools by name where relevant.
```
